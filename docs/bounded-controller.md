# Контроллер с ограниченным распределением возбуждений

## Что исправлено

В Gaussian-опытах средние команды уходили ниже нуля. После обрезания разные
пробы давали одинаковое нулевое возбуждение; уменьшение шума делало выход из
этого режима практически непосещаемым. Кроме того, обрезанное среднее не равно
среднему приложенному возбуждению. Измерения — в [ppo-diagnosis.md](ppo-diagnosis.md).

Новая `BetaExcitationPolicy` использует Beta-распределение отдельно для каждой
из шести мышц. По умолчанию actor имеет два скрытых слоя по 128 Tanh;
`--hidden-layers` задаёт ширины actor и critic. Выход actor — 12 параметров:
`alpha = softplus(raw_alpha) + 0.05`, `beta = softplus(raw_beta) + 0.05`.
Пробы лежат в (0,1), детерминированное действие — точное среднее `alpha/(alpha+beta)`.
SB3 по-прежнему ограничивает Box-действия перед средой, но здесь это не меняет
выбранные пробы. Log-probability считается для тех же физических возбуждений.
Политика не содержит эвристики и не получает её выходы как метки.

Начальные alpha≈1, beta≈9 задают всем мышцам одинаковое среднее ≈0.1 и
стандартное отклонение ≈0.09. Это общий prior, а не предварительно обученный
контроллер. Параметры распределения зависят от наблюдения и обучаются вместе
с actor. Нижняя граница параметров распределения не является нижней границей
выбранного возбуждения и не гарантирует охват всех полезных реакций.

В первом варианте независимая проба выбиралась каждые 20 ms. После 58880
сохранённых шагов оценка почти не улучшилась: 43.213→43.148, движения 0/12.
Серия остановлена для изменения исследования, а не по формальному критерию
трёх устаревших блоков. До прерывания собрано не менее 73600 шагов, но веса
после 58880 не сохранены и не входят в результат. Снимок использованного runner
сохранён как `runs/train_bounded_independent_v1.py`.

### Завершённый эксперимент со связью команд во времени

Этот вариант сохранён для воспроизводимости прошлых checkpoint. Он задаёт
искусственную динамику контроллера, включая deterministic-действия; её
биологическое обоснование не установлено. Серии с одной и десятью эпохами
вышли на плато без освоения упражнений. Для дальнейшей работы сохраняется
семантика прямого возбуждения мышц; история служит входом сети, без обязательного
смешивания с прошлой командой.

`PersistentBetaPolicy` использует последнее фактически выданное возбуждение
из `history/1/excitation/*`. Среднее следующей условной пробы:

`m = 0.9 * previous_excitation + 0.1 * alpha/(alpha+beta)`.

Концентрация `k=alpha+beta` сохраняется; новое условное распределение —
`Beta(m*k, (1-m)*k)`. Это явно заданная авторегрессионная policy, не внешнее
сглаживание уже выбранного действия. Выборка, deterministic-действие и
log-probability используют одно распределение. При PPO-replay предыдущее
возбуждение извлекается из записанного наблюдения, не из живого состояния среды.
У сети остаются прежние два скрытых слоя; шесть прошлых возбуждений передаются
к выходной голове также напрямую. Нормализация этого пути сохраняется в buffers.

Такое исследование связано во времени без удерживания случайной добавки
с неправильной log-probability. У необученной policy с seed 0 в номинальном
10-секундном подъёме посещён угол 99.40°; это охват, а не освоенная команда.
При коэффициенте 0.97 в отдельной пробе максимум 59.06°: более сильная связь
не обязана давать лучший охват. Для обучения выбран 0.9, исходно соответствующий
времени затухания около 190 ms. Один seed не устанавливает общий порядок вариантов.
Отчёт — `runs/d1_persistent_beta_coverage.json`.

gSDE в Beta-вариантах не используется. Моторная задержка 40 ms, активация,
физика и сухожилия сохранены. Зависимость policy от прошлой команды также
меняет её deterministic-динамику, поэтому это не изолированная замена шума.

## Воспроизведение диагностического обучения

Это воспроизведение неуспешной серии, а не готовый способ получить демо.
Без `--persistence` выходы задают прямые возбуждения:

```bash
.venv/bin/python3 -m myo.train_bounded --output-dir runs/d1_direct_beta_diagnostic
```

Команда исторического авторегрессионного опыта:

```bash
.venv/bin/python3 -m myo.train_bounded --persistence 0.9 \
  --output-dir runs/d1_bounded_persistent_beta
```

Требуется подготовленная MyoArm и замороженный набор наблюдений
`runs/d1_ppo_diagnosis/frozen_rollouts.npz` с соседним `collection.json`.
Если его нет, собрать без обновлений сети:

```bash
.venv/bin/python3 scripts/diagnose_compact_ppo.py --phase collect
```

Из этого набора используются только статистики входных наблюдений обучающих
целых эпизодов; действия/GAE-метки не участвуют в обучении новой policy.
Статистики центрирования сохраняются внутри checkpoint. Физический SHA и
конфигурация набора проверяются до использования. Иной путь задаётся `--statistics`.

Остальные условия: CPU, один поток PyTorch, seed 0, MLP actor/critic 128×128,
rollout 1472, minibatch 64, до 10 эпох, lr=0.0003, gamma=0.99, lambda=0.95,
target KL=0.02, reward/value масштабированы на 0.01, энтропийный бонус выключен.
Обучение с нуля, без восстановления прежних Gaussian-весов.

Используются прежние 18 упражнений с грузом 1 kg, trigger 0.3/0.6/1,
начальной capacity 1/0.8: проход 15–150° вверх/вниз, подъём 20→75°,
опускание 75→20°. Награда и критерии `behavior_summary` сохранены.
Набор не обучает отпусканию trigger=0 и не доказывает полноценную защиту D1.

Каждые два круга (29440 фактических шагов с округлением rollout) выполняется
детерминированная проверка всех упражнений без расходования учебного RNG.
Сохраняются каждый блок, `best.zip` с metadata, сценарные отчёты и аудит
распределения. Остановка — прохождение критериев или три блока без улучшения
хотя бы max(0.5, 2% опорной оценки). Это инженерное плато, не доказательство
невозможности дальнейшего обучения. Более долгая серия сама по себе не цель.

Продолжение из сохранённого блока в новый каталог:

```bash
.venv/bin/python3 -m myo.train_bounded --persistence 0.9 \
  --resume runs/d1_bounded_persistent_beta/best.zip --output-dir runs/d1_bounded_resumed
```

Восстанавливаются actor/critic, Adam и счётчик шагов; новый физический эпизод
и seed 0 не являются полным восстановлением состояния симулятора/RNG.
При новом запуске отсчёт плато начинается заново. Внутри непрерывной серии
среда и RNG между блоками сохраняются.

## Сохранение и проверка

Checkpoint v2 сохраняет модель, порядок наблюдений/действий, timing,
нормализацию, протокол, масштаб награды и SHA `policy_beta.py`. Runtime
отклоняет отсутствующий/изменённый fingerprint bounded-policy. Исторические
Gaussian/gSDE checkpoints используют собственные прежние контракты.
Файлы новой policy и `policy_exploration.py` разделены, чтобы не инвалидировать
уже сохранённые экспериментальные веса gSDE.
Авторегрессионный вариант дополнительно хранит коэффициент связи и SHA
`policy_persistent_beta.py`. Продолжение с другим коэффициентом отвергается.

Тесты проверяют реальный обнаруженный провал: в низком диапазоне возбуждений
остаются ненулевые существенные пробы, все пробы физически допустимы, их
эмпирическое среднее соответствует deterministic-действию. Дополнительно
проверены конечные log-probability/градиенты, обновление PPO и сохранение/загрузка.
Для условного распределения проверены восстановление прошлого возбуждения из
нормализованной истории и совпадение log-probability при сборе/replay после
перемешивания minibatch; скрытого состояния между вызовами policy нет.
Фактические результаты обучения и пределы применения — в [validation.md](validation.md).

## Сравнение ширины и глубины MLP — 2026-11-02

Проверяется гипотеза, что раннее сжатие 773 входов в 128 компонент ограничивает
полезное представление. Новый вариант: actor `773→1024→1024→512→12`,
critic `773→1024→1024→512→1`. Одновременно с ним заново запущен прежний
`773→128→128`, чтобы сравнивать одинаковое число физических шагов.
Это совместное изменение ширины и глубины, а не отдельная оценка каждого фактора.

```bash
.venv/bin/python3 -m myo.train_bounded --hidden-layers 128 128 \
  --output-dir runs/d1_architecture_small_tanh
.venv/bin/python3 -m myo.train_bounded --hidden-layers 1024 1024 512 \
  --output-dir runs/d1_architecture_wide_tanh
```

В обоих случаях прямые Beta-возбуждения без фиксированной памяти команды,
Tanh, без LayerNorm/residual, одинаковые центрирование, физика, PPO, seed 0,
18 упражнений и прежняя остановка по готовности/плато. Инициализация с нуля;
веса разных размеров не могут совпадать. Малый вариант побитово воспроизводит
историческую начальную policy. Масштаб начальной концентрации Beta одинаков.
Изменение архитектуры меняет последовательность потребления RNG; одинаковый seed
не означает одинаковые стохастические траектории двух сетей. Один seed достаточен
для этой диагностической пробы, но не доказывает общего превосходства архитектуры.

`network_architecture` в metadata сохраняет число входов, скрытые слои,
активацию и общее число обучаемых параметров actor/critic. ZIP хранит саму
архитектуру; при `--resume` необходимо явно задать те же `--hidden-layers`.
Переключение размера при продолжении отвергается. Timing каждого блока разделяет
обучение и оценку; сопоставляем поведение при равном числе шагов, отдельно затраты
времени. Снимок runner сохраняется в каталоге каждого опыта.

Обе серии завершились **по плато на 117760 шагах**, без успешных движений
или проходов. Увеличение числа параметров с 232845 до 4740621 не вывело руку
из области нижнего упора. С 2026-11-03 обучение остановлено по решению владельца;
дальнейшие пробы выполняются с замороженными весами. Полные числа —
в [validation.md](validation.md), разбор причин и сравнение с MuscleMimic —
в [controller-learning-review.md](controller-learning-review.md).
